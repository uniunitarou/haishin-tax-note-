# 配信者の確定申告ノート（PWA）

## 含まれるもの
- ホーム画面に追加できるPWA用ファイル一式
- 収入・経費の記録、年次集計、検索・編集・削除
- 取引ごとの画像/PDF添付（IndexedDBに保存）
- JSONバックアップ/復元（添付データを含む）、CSV出力
- オフライン起動用のService Worker

## 使い始めるには
PWAとしてホーム画面にインストールするには、HTTPSで公開する必要があります。ZIPを展開し、中身のファイル一式をGitHub PagesなどのHTTPS対応静的ホスティングへアップロードしてください。公開URLをAndroidのChromeで開き、メニュー（︙）→「ホーム画面に追加」または「アプリをインストール」を選びます。表示文言は環境により異なります。

## 注意
- このパッケージ自体はWeb上に公開されていません。インストール前にHTTPSでホスティングする必要があります。
- データは端末・ブラウザ内のIndexedDBに保存され、端末間同期はありません。定期的にJSONバックアップを取ってください。
- ブラウザのデータ消去や端末故障で記録が失われる可能性があります。
- これは記帳補助ツールであり、税額計算、申告要否の判定、e-Tax送信は行いません。税務判断は税務署・税理士等に確認してください。
- 画像/PDFを含むバックアップには個人情報が入る場合があります。安全な場所に保管してください。
